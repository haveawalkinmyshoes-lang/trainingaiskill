# MCP-мост Нейротренера

Административный адрес: `https://neurotrainer.onrender.com/mcp`.
Streamable HTTP (POST, JSON), stateless, версии MCP 2025-03-26, 2025-06-18 и 2025-11-25.
GET возвращает 405: сервер не поддерживает отдельный SSE-поток.

## Подключение

1. В Render откройте **neurotrainer → Environment → Secret Files → Add file**.
2. Имя: `neurotrainer-bridge.env`. Содержимое: из локального файла `app/private/neurotrainer-bridge.env`. Сохраните с развертыванием. Альтернатива: добавьте его переменную через Add from .env в Environment Variables.
3. Установите частный плагин «Нейротренер — мост». При подключении введите значение `TRAINER_BRIDGE_TOKEN` из этого файла как API key, без имени переменной и без префикса Bearer.
4. После подключения запросите `trainer_status`. Наличие плагина само по себе не подтверждает авторизацию; проверьте вызов инструмента.

Не вставляйте ключ в чат, Git, адрес ссылки или браузерный интерфейс тренажера. Это отдельный административный ключ, он не совпадает с ключами OpenAI или Битрикс24. Без него /mcp возвращает 401; без серверной настройки мост возвращает 503. Для отзыва доступа смените TRAINER_BRIDGE_TOKEN на сервере и переподключите плагин с новым ключом.

## Возможности

- `trainer_status`: версия коммита, настройка подключения ИИ/Битрикс24, лимиты, темы, количество сценариев и профилей. Наличие ключа не равно работоспособности API.
- В `trainer_status.ai.lastFailure` сохраняются время и безопасные признаки последнего отказа API (категория, HTTP-статус, известный код, Retry-After в секундах). Исходные ответы провайдера и пользовательские реплики не сохраняются. `lastSuccessAt` — время последнего успешного вызова адаптера API, а не подтверждение всей тренировки. Поля очищаются при перезапуске. Чтение статуса не вызывает платный API.
- `trainer_statistics`: только обезличенные счетчики сохраненных сессий текущего процесса, не пожизненная статистика. Сессии удаляются через 12 часов, при выходе и перезапуске.
- `trainer_recent_errors`: до 100 событий с временем, областью и HTTP-статусом (ошибки 5xx и ограничения 429), без текстов исходных ошибок или переписки. С момента запуска моста, без истории прошлых развертываний.
- `trainer_profiles`: справочник матрицы, поиск и страницы по 50 профилей. Не реестр сотрудников.
- `trainer_scenarios` и `trainer_explain_scenario`: доступность сценариев для профиля и целевые уровни компетенций.
- `trainer_check_ai`: один платный запрос проверки с confirm=true, не чаще раза в минуту, с общим дневным лимитом ИИ.
- `trainer_render_deploys`: пять последних развертываний фиксированного сервиса; требует Render API.
- `trainer_render_deploy`: доступен только при TRAINER_BRIDGE_ALLOW_DEPLOY=true. Запускает последний коммит текущей ветки, без сброса кеша, не чаще раза в 5 минут, только с confirm=true. Ответ accepted означает принятие запроса, а не успешное развертывание.

## Дополнительно: Render API

Для управления Render добавьте на сервере **RENDER_API_KEY** и **RENDER_SERVICE_ID** (ID именно neurotrainer).
Ключ Render берется из настроек вашего аккаунта Render. Его нельзя передавать в чат.
Для запуска публикации также задайте **TRAINER_BRIDGE_ALLOW_DEPLOY=true**.
Эти переменные можно внести в Environment Variables либо в тот же закрытый neurotrainer-bridge.env. Встроенный RENDER_SERVICE_ID, если он уже задан хостингом, имеет приоритет.

У моста нет функций чтения переменных окружения, файлов, почты/ФИО, кодов входа, пользовательских диалогов и исходных логов. Нет shell, произвольных HTTP URL, отправки сообщений и изменения списка допуска. Cookie сотрудников не авторизуют MCP. Административный токен не авторизует API сотрудников.

Мост выполняет запросы, когда подключенный ИИ вызывает инструменты; он не является постоянно работающим наблюдателем. При сне бесплатного Render вызов также ждет запуска сервиса.

## Проверки

`node --test app/tests/*.test.mjs`

Тесты проверяют авторизацию, Origin/Host, JSON-RPC, ограничения запросов/аргументов, отсутствие персональных данных в диагностике, защиту платной проверки и публикации, фильтрацию ответа Render. Render и ИИ в тестах подменены: реальные платные вызовы и публикации не выполняются.
