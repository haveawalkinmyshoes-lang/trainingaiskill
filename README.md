# Нейротренер

Диалоговые тренировки по управлению временем, SMART и обратной связи. Включены 45 сценариев и 250 вариантов должностей, шкала 0–3 с шагом 0,5, рефлексия и план практики на следующий месяц.

## Публикация на Render

Создайте Blueprint из этого репозитория. Файл `render.yaml` настраивает бесплатный Node Web Service, команду запуска и проверку состояния. Корневая папка сервиса — корень репозитория. Если создаете Web Service вручную: Build Command `node --check app/server.mjs`, Start Command `node app/server.mjs`, Node.js 24.19.0, `NODE_ENV=production`.

В защищенных Environment-настройках Render задайте `OPENAI_API_KEY`. Не добавляйте ключ в GitHub. В публичной версии без ключа тренировки недоступны. Модель задается через `OPENAI_MODEL`; по умолчанию `gpt-6.1-sol`. Персонаж, оценки и план используют выбранную модель. Запросы оплачиваются с баланса OpenAI API.

Для смены модели: Render → neurotrainer → Environment → Edit → `OPENAI_MODEL=gpt-6.1-sol`, `AI_API_STYLE=responses` → Save, rebuild, and deploy. Если сервис управляется Blueprint, то же значение задано в `render.yaml`. Явная переменная окружения имеет приоритет над значением по умолчанию в коде. После публикации фактическую модель можно увидеть в настройках ИИ на сайте или через `trainer_status` защищенного моста. Изменение применяется к новым тренировкам.

Sol 6.1 использует reasoning effort `low`; лимит ответа 8000 токенов оставляет запас для reasoning и структурированного ответа. Для остальных моделей сохраняется прежний формат запроса. Проверка доступа и ролей через мост поддерживает `trainer_check_ai` с `confirm=true` и `model=gpt-6.1-sol`, не меняя рабочую конфигурацию. Официальные характеристики: [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol).

Render автоматически задает `PORT` и `RENDER_EXTERNAL_URL`. Для собственного домена задайте `PUBLIC_URL=https://ваш-домен`. Сервер в production слушает `0.0.0.0`, настройки модели закрыты для посетителей, история изолирована браузерными сессиями. Общий ограничитель пилота — 200 обращений к ИИ за 24 часа работы процесса; можно задать `MAX_AI_CALLS_PER_DAY`. Это ограничитель нагрузки, не финансовый лимит: он сбрасывается при перезапуске. Установите денежный бюджет у провайдера.

Бесплатный Render засыпает после 15 минут без запросов; первое открытие может занять около минуты. История хранится в памяти процесса и исчезает при перезапуске или засыпании. Скачивайте итог тренировки кнопкой в интерфейсе. Это версия для небольшого пилота без постоянной базы и аккаунтов сотрудников. Доступ к интерфейсу открыт по ссылке; скрытые факты сценариев и серверные секреты через HTTP не выдаются.

Хостинг Free не включает расходы на API модели. Условия: [Render Free](https://render.com/docs/free).

## Локальный запуск и проверки

Node.js 22 или новее: `node app/server.mjs`, затем http://127.0.0.1:8765/. Зависимости для запуска не требуются.

Проверки: `node --test app/tests/*.test.mjs`. Настоящая модель требует отдельной проверки с действующим ключом.

Два Markdown-документа в корне содержат библиотеку сценариев и правила модели вместе с конфигурацией должностей и матрицей оценки. Сервер читает второй документ при запуске. Подробности — в `app/README.md`.
